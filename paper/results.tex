\textbf{Statistical Report:} A Shapiro-Wilk normality test rejected normality for all four metrics ($p < 0.001$). Since the reduced matrix contains only the TDMA+packet loss baseline, ANOVA across baselines yields $F = \text{nan}$; however, the confidence intervals for the TDMA+packet loss baseline are:
\begin{itemize}
    \item MTC: $31.26 \pm 0.53$\,s (95\% CI: [30.22, 32.30])
    \item SCI: $0.477 \pm 0.002$ (95\% CI: [0.472, 0.481])
    \item CE: $0.759 \pm 0.008$ (95\% CI: [0.743, 0.776])
    \item PDR: $0.937 \pm 0.001$ (95\% CI: [0.934, 0.940])
\end{itemize}

The correlation analysis reveals a strong negative correlation between packet loss rate and PDR ($r = -0.993$), a moderate positive correlation between swarm size and MTC ($r = 0.723$), and a moderate negative correlation between packet loss rate and SCI ($r = -0.279$). Swarm size and CE show a moderate positive correlation ($r = 0.424$).

\textbf{Figures:}
\begin{itemize}
    \item \textbf{mtc\_vs\_swarm\_size.png}: MTC increases approximately linearly with swarm size under TDMA, consistent with the theoretical bound $T_{TDMA} \leq T_{ideal} + N \tau K$.
    \item \textbf{pdr\_vs\_packet\_loss.png}: PDR degrades gracefully with increasing $p$; at 15\% loss PDR $> 93\%$, at 30\% loss PDR $\approx 85\%$.
    \item \textbf{convergence\_curve.png}: The empirical CDF shows consensus typically reached within 100 frames under moderate conditions.
    \item \textbf{heatmap.png}: MTC grows with both swarm size and packet loss, confirming the linear scaling.
    \item \textbf{boxplot.png}: Distributions show MTC skewed toward higher values at larger swarm sizes and higher packet loss rates.
\end{itemize}
